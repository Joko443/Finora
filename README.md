# Finora

Finora is a lightweight DeFi and open finance smart contract project built on OPN Testnet.

## Overview

Finora explores decentralized and transparent financial interaction through smart contracts.

## Features

* Smart contract deployment
* Open finance experimentation
* Transparent transactions
* EVM-compatible architecture

## Technology Stack

* Solidity
* Remix IDE
* MetaMask
* OPN Testnet

## Deployment

Successfully compiled and deployed on OPN Testnet.

## Future Plans

* Open financial infrastructure
* DeFi experimentation
* Web3 integrations
